6️⃣ Understanding the Flow

        

✅ WITH PROXY/RELAYER (Recommended):
1. Send raw JSON → POST /put
2. Get certificate back
3. Use certificate to retrieve → GET /get/{certificate}
4. Data comes back DECODED automatically! ✨

⚠️ WITHOUT PROXY (Direct gRPC):
1. Base64 encode your data
2. Call DisperseBlob via grpcurl
3. Get request_id back
4. Check status with GetBlobStatus
5. Retrieve with RetrieveBlob when confirmed
6. Data comes back ENCODED - you must decode it! 😓

Key Difference:
• Proxy/Relayer: Handles ALL encoding/decoding for you
• Direct gRPC: Returns encoded data, you decode manually

The blob hash can be stored in your smart contract as bytes32!
